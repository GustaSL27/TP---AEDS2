# TP AEDS II - Índice Invertido (2026/1)

Este projeto foi desenvolvido como Trabalho Prático para a disciplina de **Algoritmos e Estruturas de Dados II** da **Universidade Federal de Viçosa (UFV) - Campus Florestal**.

---

## Estrutura do Projeto

* `main.c`: Ponto de entrada do programa e controle do menu.
* `hash/`: Módulo contendo a implementação da Tabela Hash com tratamento de colisão por lista encadeada.
* `PATRICIA/`: Módulo contendo a implementação da Árvore PATRICIA adaptada para comparação de caracteres.
* `menu/`: Módulo responsável pela interface de texto e interação com o usuário.
* `*.txt`: Arquivos de fábulas utilizados como entrada para alimentar o índice.

---

## Como Compilar e Rodar

O projeto possui um `Makefile` configurado para facilitar a execução tanto em ambientes Windows quanto Linux.

### Comando Principal (Compilar e Rodar)
Para limpar compilações antigas, atualizar as alterações do código, gerar o executável e iniciar o programa automaticamente, utilize `mingw32-make` no terminal
